# Этап 4: транзакции и конкурентные сессии

Дата: 9 октября 2026 года. Статус: **этап принят**. Linux/macOS CI success; этап 5 начат по поручению пользователя.

Реализованы local Session API, autocommit/BEGIN/COMMIT/ROLLBACK, совместные читатели и один писатель, справедливая очередь, admission bound, таймауты/отмена, aborted и disconnect rollback. READ ONLY не пишет WAL и не повышается до writer. Cache hits и private I/O проверяют cancellation/deadline. SQL/protocol еще впереди.

Первые конкурентные истории прошли для 1, 2, 8, 32 клиентов с rollback, отменой, disconnect/reconnect и проверкой сохраненных acknowledgements. Все подтвержденные обновления счетчика образуют последовательность без пропусков и повторов; отмененные группы не видны. Проверены shared readers, writer fairness, lock timeout, lifetime/idle expiry, oversized request и private write set failure.

Локально прошли format, Clippy с `-D warnings`, 71 debug + 71 release tests и release build. [Логи и SHA-256 исходников](results/2026-10-09-stage4/summary.json) фиксируют проверенный снимок.
