# Чек-лист выпуска 1.0

Статус: не пройден. Каждый пункт получает ссылку на проверку, отчет или документ, точный commit и дату. Этот файл задает условия, не утверждает их выполнение.

## Продукт и границы

- [ ] Зафиксирован первый пользователь, обязательные запросы и поддерживаемый объем.
- [ ] Описаны ограничения одного узла, одного писателя, типов, SQL, клиентов и платформ.
- [ ] Конкурентная цель скорости определена до итогового сравнения и подтверждена по BENCHMARKS.md.
- [ ] Понятно, как установить продукт и перенести данные из поддерживаемого источника.
- [ ] Есть подтвержденный путь экспорта обратно в PostgreSQL для поддерживаемого подмножества.

## Данные и транзакции

- [ ] Поддерживаемые SQL-сценарии дают правильный результат и проверены независимо.
- [ ] Пределы типов, NULL, constraints и параметры проверены.
- [ ] Случайные операции хранения совпадают с эталонной моделью.
- [ ] Целостность таблиц/индексов/каталога проверяется инструментом.
- [ ] Приватные изменения не видны другим транзакциям и не попадают преждевременно в data file.
- [ ] BEGIN/COMMIT/ROLLBACK и aborted state проверены при ошибках и disconnect.
- [ ] Изоляция подтверждена конкурентными историями.
- [ ] Лимиты, таймауты и отмена освобождают ресурсы.
- [ ] Подтвержденные клиенту транзакции сохраняются после отказов в заявленной модели.
- [ ] Recovery, checkpoint, WAL rotation и частичная запись испытаны управляемыми сбоями.
- [ ] Сбой при recovery и неоднозначный исход fsync обработаны.
- [ ] Повреждение и неизвестный формат дают диагностируемый отказ.
- [ ] Нет открытых известных дефектов потери данных или существенного неправильного результата.

## Сеть и эксплуатация

- [ ] Аутентификация и TLS проверены; секреты не появляются в логах.
- [ ] Сервер по умолчанию не выставлен на все сетевые интерфейсы.
- [ ] Неправильные и частичные пакеты не приводят к panic/OOM/зависанию.
- [ ] Поддерживаемый протокол, типы и драйверы перечислены с проверенными версиями.
- [ ] Startup, graceful shutdown, cancel и reconnect проверены.
- [ ] Второй процесс не может открыть тот же каталог для записи.
- [ ] Заполнение диска и превышение памяти дают контролируемое поведение.
- [ ] Backup с проверяемым manifest создан и восстановлен на другой машине.
- [ ] После restore сравниваются данные, схема и ограничения, а не только успешный запуск.
- [ ] Логи, метрики и инструкции позволяют диагностировать типовые проблемы.
- [ ] Установка и восстановление пройдены независимым пользователем по инструкции.
- [ ] Версии дискового формата и путь обновления документированы и испытаны.

## Производительность и полевые испытания

- [ ] Нагрузки, основной показатель, конкуренты и условия зафиксированы заранее.
- [ ] Финальные benchmark-прогоны проведены после стабилизации release candidate.
- [ ] Участники сравниваются при одинаковых гарантиях и сопоставимых ресурсах.
- [ ] Данные/результаты проверены до зачета показателей скорости.
- [ ] Сохранены пять независимых прогонов, разброс, tail latency и raw data.
- [ ] Измерены объем сверх кэша, checkpoint, долгие клиенты и смешанные операции.
- [ ] Достигнуто подтвержденное первое место среди выбранных участников на выбранной основной нагрузке; ничья/неясный результат не выдается за победу.
- [ ] Пределы заявления лидерства и проигранные сценарии опубликованы в отчете.
- [ ] Получено независимое воспроизведение или дополнительная аппаратная проверка.
- [ ] Непрерывный нагрузочный прогон не менее 72 часов пройден.
- [ ] Минимум два независимых пилота завершили согласованный период beta.
- [ ] Критичные подсистемы рассмотрены специалистом, замечания разрешены или явно блокируют выпуск.

## Поставка

- [ ] Release commit зафиксирован; обязательные доказательства относятся к нему.
- [ ] Процедура сборки и toolchain закреплены, Cargo.lock сохранен.
- [ ] Подготовлены сборки заявленных платформ, контрольные суммы и перечень зависимостей.
- [ ] Лицензия и уведомления сторонних компонентов проверены.
- [ ] Готовы quickstart, SQL reference, ограничения и примеры клиента.
- [ ] Готовы backup/restore, operations, upgrade и rollback инструкции.
- [ ] Есть release notes, порядок приема ошибок и сообщений об уязвимостях.
- [ ] Есть ответственный за поддержку первой версии и ясные ожидания пользователя.
- [ ] Публикация и внешние сообщения отдельно разрешены пользователем.
